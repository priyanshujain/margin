# margin

Write your book. Own every word. A calm, offline studio to write, format, and publish your book to every store and to print.

Download it from [margin.73ai.org](https://margin.73ai.org), or install it with Homebrew:

```
brew tap priyanshujain/margin
brew trust priyanshujain/margin
brew install --cask margin
```

How releases are signed and where they go is in [docs/publishing.md](docs/publishing.md).
